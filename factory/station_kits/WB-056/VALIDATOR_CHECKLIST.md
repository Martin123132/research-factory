# Independent validator checklist — WB-056

You are checking an immutable claim, not helping the author tune it.

- Confirm you are a different human from the author and the other validator.
- Declare affiliations, shared employment, prior collaboration and account aliases.
- Lock the contract, input, artifact, environment and command hashes before running.
- Do not view the author's result or the other validator's result before committing yours.
- Run every hard gate. Missing evidence, malformed output, verifier failure or timeout fails closed.
- Apply this station's equivalence tolerance; never substitute a universal percentage.
- Keep correctness, improvement and safety thresholds separate.
- Commit the conclusion and evidence hash before reveal.
- If deterministic results differ, open a dispute. A third run diagnoses; it does not create a majority vote.
- Preserve a sound negative result with enough detail to stop the same search being repeated.

This construction kit is not scientific evidence and cannot award reproduction or promotion credit.
