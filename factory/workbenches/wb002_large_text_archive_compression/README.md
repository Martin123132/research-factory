# WB-002 — Large-text and knowledge-archive compression

WB-002 is the first station bound through the reusable
`DIGITAL_COMPRESSION_V1` commissioning adapter.

It has two result scopes which must never be conflated:

1. `HUTTER_OFFICIAL_COMPATIBLE` measures the exact public `enwik9` challenge.
2. `PRACTICAL_ARCHIVE_UTILITY` measures a separately frozen deployment cost.

The local known-answer fixture and the `enwik8` entry exercise are
`ENTRY_GATE_ONLY — ZERO SCIENTIFIC CREDIT`. They show that a contributor can
acquire and hash a corpus, run a locked candidate, prove exact restoration,
count package bytes and preserve evidence. They do not count as progress on
`enwik9`, a scientific result, or an independent reproduction.

This station remains `CONTRACT_DRAFT`. See `commissioning.json` for the exact
unresolved boundaries.
